# 账号与多租户 — 实施记录(2026-09-13)

**Spec:** `docs/superpowers/specs/2026-09-13-accounts-design.md`。本文记录实际落地的层次与验证,供后续会话对照。

## 落地层次
1. **Schema v15 + 迁移**(`src/lib/schema.sql`、`src/lib/db.ts` `migrateV15`):Better Auth 四表 + `profiles` + `api_tokens`;七张个人表加 `user_id`(DEFAULT `'legacy'`);`matches/applications/people/resumes` 因唯一约束改变按 sqlite 官方方式重建(临时表 → 拷列 → drop → rename,外键关闭);`events.user_id` 可空。索引在 db.ts 里建(schema.sql 先于旧库加列执行)。测试:`tests/migration-v15.test.ts`。
2. **账号与租户模块**:`src/lib/users.ts`(owner 认领、回填、清除)、`src/lib/profile.ts`(库存档案)、`src/lib/api-tokens.ts`、`src/lib/internal-token.ts`、`src/lib/mailer.ts`、`src/lib/auth.ts`、`src/lib/actor.ts`、`src/lib/session.ts`、`src/middleware.ts`。测试:`tests/users.test.ts`、`tests/actor.test.ts`。
3. **领域模块按账号取数**:`src/apply/*`、`src/matcher/*`、`src/network/*`、`src/resume/*`、`src/executor/*`、`src/scanner/{upsert,relay}.ts`、`src/jd-review/*` —— 每个函数多一个 `userId` 参数(或 `opts.userId`)。测试:`tests/tenancy-isolation.test.ts`(两个账号互不可见)、`tests/tenancy-guard.test.ts`(静态检查)。
4. **API 路由**:全部经 `withUser`(tick / dispatch 经 `withInternal`);新增 `GET/PUT/POST /api/profile`、`/api/account/tokens`、`/api/account/password`、`/api/auth/[...all]`。
5. **前端**:`(auth)` 路由组五个页面;`(app)` 路由组统一 `requireUser`;侧栏用户胶囊;设置页「账号」区;档案页「基本信息」标签;首页档案未完善横幅;401 自动跳登录。
6. **执行协议**:提示词里的每条 curl 带运行令牌(`curlCmd`);调度器拉起的 CLI 会话同理;桌面会话用 `data/internal-token`;三个 skill 文件加「0. Authentication」;`deploy.ps1` 带头;`instrumentation.ts` 用 `process.getBuiltinModule` 读令牌(仍然零 import)。
7. **脚本**:`scripts/match.ts`、`scripts/referral-fit.ts` 加 `--user <email>`(默认主账号,`scripts/script-user.ts`)。

## 验证(2026-09-13,本机)
- `npm test`:93 文件 / 794 用例全绿;`tsc --noEmit` 干净;`next build` 通过。
- 生产库快照(475 MB,jobs 78k / matches 58k / applications 84k)在 3001 端口实测:注册第一个账号 3 秒(含迁移),日志 `became owner, claimed legacy rows {matches:57867, applications:83859, people:3, outreach:4, resumes:12, experiences:38, executor_runs:69}`,档案导入完整;第二个账号 0.6 秒回填 83859 行,队列/任务/匹配为空,访问主账号专属接口 403;个人令牌可用、撤销后 401;内部令牌以主账号身份工作、不能碰 dispatch 之外……(见会话记录);验证邮件链接、退出、错误密码、找回密码全流程走通;Better Auth 内置限流生效(sign-in 10 秒 3 次)。
